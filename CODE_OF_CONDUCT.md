# Code of Conduct

We want a friendly, respectful project. This applies to issues, pull requests and every other space around Snapious.

* Stay respectful and factual; criticize the work, not the person.
* No insults, harassment, discrimination or personal attacks.
* Do not publish other people's private information.
* Different experience levels and opinions are fine; explain kindly instead of putting others down.

Contributions that break these rules may be edited or removed; repeat offenders will be banned.
Report problems privately to the maintainer through a GitHub private security advisory or a message to the maintainer's profile.
