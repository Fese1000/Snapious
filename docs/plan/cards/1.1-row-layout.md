# Card 1.1: Row layout of the sequence view

File: `crates/snapious-core/src/view/seq_layout.rs` (skeleton and tests are present)
Prerequisite: none (uses `crates/snapious-core/src/error.rs`)

Goal: A sequence is split into rows of fixed length; positions and visible rows can be computed.

Functions (bodies are `todo!()` and must be replaced):

```
SequenceLayout::new(length, bases_per_line) -> Result<Self>   // bases_per_line == 0 → Err(Error::InvalidInput(..))
line_count() -> usize            // ceil(length / bases_per_line), for length 0: 0
line_of(position) -> usize       // position / bases_per_line
column_of(position) -> usize     // position % bases_per_line
line_start(line) -> usize        // line * bases_per_line
line_end(line) -> usize          // min(line_start + bases_per_line, length)
first_visible_line(scroll_y, line_height) -> usize
                                 // floor(scroll_y / line_height); for scroll_y <= 0 or line_height <= 0: 0
last_visible_line(&self, scroll_y, view_height, line_height) -> usize
                                 // floor((scroll_y + view_height) / line_height), capped at line_count() - 1
                                 // (for 0 lines: 0); for line_height <= 0: 0
bases_per_line_for(view_width, char_width, margin_width, group_size) -> usize
                                 // treat group_size 0 as 1
                                 // group width = (group_size + 1) * char_width
                                 // available = max(view_width - margin_width, 0)
                                 // groups = floor(available / group width), at least 1
                                 // result = groups * group_size
```

Numeric examples (also present as tests):
- Length 125, 60 per row → 3 rows; `line_end(2)` = 125.
- `bases_per_line_for(800, 10, 80, 10)`: group width 110, available 720 → 6 groups → 60.
- `first_visible_line(250, 20)` = 12; `last_visible_line` with 100 rows, scroll 250, height 100, row height 20 → 17.
