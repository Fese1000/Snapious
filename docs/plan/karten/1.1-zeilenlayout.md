# Karte 1.1: Zeilenlayout der Sequenzansicht

Datei: `crates/snapious-core/src/view/seq_layout.rs` (Gerüst und Tests sind vorhanden)
Voraussetzung: keine (nutzt `crates/snapious-core/src/error.rs`)

Ziel: Eine Sequenz wird in Zeilen fester Länge aufgeteilt; Positionen und sichtbare Zeilen lassen sich berechnen.

Funktionen (Rümpfe sind `todo!()` und müssen ersetzt werden):

```
SequenceLayout::new(length, bases_per_line) -> Result<Self>   // bases_per_line == 0 → Err(Error::InvalidInput(..))
line_count() -> usize            // ceil(length / bases_per_line), bei length 0: 0
line_of(position) -> usize       // position / bases_per_line
column_of(position) -> usize     // position % bases_per_line
line_start(line) -> usize        // line * bases_per_line
line_end(line) -> usize          // min(line_start + bases_per_line, length)
first_visible_line(scroll_y, line_height) -> usize
                                 // floor(scroll_y / line_height); bei scroll_y <= 0 oder line_height <= 0: 0
last_visible_line(&self, scroll_y, view_height, line_height) -> usize
                                 // floor((scroll_y + view_height) / line_height), begrenzt auf line_count() - 1
                                 // (bei 0 Zeilen: 0); bei line_height <= 0: 0
bases_per_line_for(view_width, char_width, margin_width, group_size) -> usize
                                 // group_size 0 wie 1 behandeln
                                 // Gruppenbreite = (group_size + 1) * char_width
                                 // verfügbar = max(view_width - margin_width, 0)
                                 // Gruppen = floor(verfügbar / Gruppenbreite), mindestens 1
                                 // Ergebnis = Gruppen * group_size
```

Zahlenbeispiele (stehen auch als Tests):
- Länge 125, 60 pro Zeile → 3 Zeilen; `line_end(2)` = 125.
- `bases_per_line_for(800, 10, 80, 10)`: Gruppenbreite 110, verfügbar 720 → 6 Gruppen → 60.
- `first_visible_line(250, 20)` = 12; `last_visible_line` bei 100 Zeilen, Scroll 250, Höhe 100, Zeilenhöhe 20 → 17.
